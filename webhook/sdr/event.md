# SDR 웹훅 이벤트

현재 구독 가능한 SDR 웹훅 이벤트는 3개입니다.

## 연락처 수집

| 이벤트 | 설명 |
| --- | --- |
| `sdr.lead.created` | SDR 프로필에서 필수로 설정한 이메일 또는 전화번호 중 하나가 유효한 값으로 처음 수집되면 알림이 발송됩니다. |

## 회사 분류 식별

| 이벤트 | 설명 |
| --- | --- |
| `sdr.segment.identified` | 방문자와 연결된 회사의 분류가 미식별 상태에서 처음 식별되면 알림이 발송됩니다.<br>이미 회사 분류가 식별된 방문자를 다시 분석한 경우에는 발송되지 않습니다. |

## 담당자 요청

| 이벤트 | 설명 |
| --- | --- |
| `sdr.handoff.requested` | 방문자가 해당 대화에서 담당자 연결이 필요하다고 처음 명시적으로 요청하면 알림이 발송됩니다. |

각 이벤트의 페이로드 예시는 [웹훅 형태](payload.md)에서 확인할 수 있습니다.
