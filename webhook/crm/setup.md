# CRM 웹훅 등록

설정 > 외부 서비스 연동 > 웹훅 등록 버튼을 클릭해 웹훅을 연동할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>

✅ 웹훅 Endpoint URL을 등록하기 전 POST 요청이 가능한 URL을 준비해 주세요.\
&#xNAN;_※_ 웹훅 Endpoint URL 등록 시, 유효성 검증을 위해 해당 URL로 POST 요청을 전송하여 응답을 확인합니다.

✅ 웹훅 Endpoint는 고객, 회사, 리드, 딜, 커스텀 오브젝트 별로 각각 설정할 수 있습니다.
