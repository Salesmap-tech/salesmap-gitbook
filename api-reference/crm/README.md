# CRM

CRM 섹션은 세일즈맵 CRM 데이터를 외부 시스템과 연동하기 위한 엔드포인트를 다룹니다.

주요 대상은 고객, 회사, 리드, 딜, 노트, 웹폼, 파일, 커스텀 오브젝트처럼 영업 활동과 CRM 데이터 관리에 직접 연결되는 리소스입니다.

## 포함되는 문서

* 필드 관리 및 `fieldList`
* 고객, 회사, 리드, 딜
* 상품, 견적서, 파이프라인
* 웹폼, 노트, TODO
* 커스텀 오브젝트
* 유저, 팀, 이메일, 파일

인증, Base URL, API 버전, Rate limiting처럼 제품과 무관하게 공통으로 적용되는 내용은 [API Reference](../README.md)의 시작하기 섹션을 참고하세요.
