# 함께 작성할 노트 입력

CRM 객체 생성·수정 API의 선택 입력 `memo`는 평문 또는 HTML을 담은 **문자열**입니다. 객체와 함께 새 노트를 작성하며, 기존 노트 본문을 수정하는 파라미터가 아닙니다.

## 적용 API

| 작업 | Method | Path |
| --- | --- | --- |
| 고객 생성 / 수정 | `POST` | `/v2/people` / `/v2/people/{peopleId}` |
| 회사 생성 / 수정 | `POST` | `/v2/organization` / `/v2/organization/{organizationId}` |
| 딜 생성 / 수정 | `POST` | `/v2/deal` / `/v2/deal/{dealId}` |
| 리드 생성 / 수정 | `POST` | `/v2/lead` / `/v2/lead/{leadId}` |
| 커스텀 오브젝트 생성 / 수정 | `POST` | `/v2/custom-object` / `/v2/custom-object/{customObjectId}` |
| 상품 생성 | `POST` | `/v2/product` |
| 견적서 생성 | `POST` | `/v2/quote` |

각 API의 필수 입력은 해당 API 문서를 따릅니다. 아래 예시는 전체 요청이 아닌 `memo` 필드 입력 예시입니다.

## 평문과 HTML 처리

* 평문은 비교 기호, 이메일·URL, 줄바꿈을 보존합니다.
* HTML 요소가 포함되면 위험한 태그·속성을 제거한 HTML 본문과 태그 없는 평문 미리보기를 저장합니다. HTML 원문이 그대로 미리보기에 표시되지는 않습니다.
* HTML 태그를 서식이 아닌 글자로 표시하려면 HTML 본문 안에서 `<`와 `>`를 `&lt;`와 `&gt;`로 이스케이프합니다.

평문 입력:

```json
{
  "memo": "1 < 2 & 3 > 2\n다음 상담 일정 확인"
}
```

HTML 입력:

```json
{
  "memo": "<p><b>상담 내용</b></p><p>다음 일정 확인</p>"
}
```

태그를 글자로 표시하는 입력:

```json
{
  "memo": "<p>&lt;b&gt;내용&lt;/b&gt;</p>"
}
```

마지막 예시의 평문 미리보기는 `<b>내용</b>`입니다.

## 실패 처리와 미리보기

* 본문 파싱·정제에 실패하면 객체 생성·수정 전에 `400 Bad Request`로 거부합니다. 오류 사유(`reason`)는 `노트 본문을 처리할 수 없습니다.`입니다.
* 본문 정제에는 성공했지만 평문 미리보기 추출만 실패하면 정제된 본문을 저장하고 미리보기를 `미리보기를 표시할 수 없습니다`로 대체합니다. 원본 HTML을 미리보기로 되돌리지 않습니다.
* 평문이 없는 이미지 전용 노트의 미리보기는 `이미지`입니다.

[노트 단일 조회](memo.md)와 [노트 목록 조회](memolist.md)의 `htmlBody`는 HTML 본문, `text`는 평문 미리보기입니다. 위 대체 문구가 `text`에 담길 수 있습니다.
