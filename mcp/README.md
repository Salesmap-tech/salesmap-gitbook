# MCP

세일즈맵 MCP를 연결하면 Codex 앱·ChatGPT·Claude에서 대화로 영업 데이터를 조회하고 관리할 수 있습니다. 별도의 API 연동 코드를 작성하거나 API 토큰을 복사할 필요 없이 **세일즈맵 계정으로 로그인해 연결**합니다.

### 무엇을 할 수 있나요?

- 딜·리드·고객·회사·커스텀 객체·할 일을 검색하고 상세 내용을 확인합니다.
- 딜 개수·금액 합계와 그룹별 현황을 집계합니다.
- 노트·활동·변경 이력, 노트 답글과 저장된 이메일 본문·녹취를 확인합니다.
- 레코드·할 일·노트·견적·일반 필드를 생성하고, 지원 객체의 레코드를 일괄 수정합니다.
- 상품·견적·파이프라인·사용자·팀·시퀀스·웹폼 정보를 조회합니다.

예를 들어 이렇게 요청할 수 있습니다.

> 내가 담당하는 딜의 개수와 금액 합계를 알려줘.
>
> 클라우드 전환 프로젝트의 최근 활동과 노트를 요약해줘.
>
> 이 딜에 오늘 미팅 내용을 노트로 남겨줘.

실제 결제·구매, 이메일 발송, 세금계산서 발행과 임의의 서버 스크립트 실행은 제공하지 않습니다.

### 이용 조건과 권한

세일즈맵 계정과 **Professional 이상 플랜**의 워크스페이스가 필요합니다. AI 서비스의 사용자 지정 MCP 연결 기능도 사용할 수 있어야 하며, 서비스의 플랜·조직 정책에 따라 관리자의 허용이 필요할 수 있습니다.

연결할 때 로그인 계정과 워크스페이스를 확인하고 접근 범위에 동의합니다.

| 연결 권한 | 할 수 있는 일 |
| --- | --- |
| 조회만 | 현재 권한 안에서 데이터 조회·검색·집계 |
| 조회 및 변경 | 조회와 지원 데이터의 생성·수정·삭제 |

**‘조회 및 변경’을 허용해도 Salesmap에서 조회 권한만 있으면 조회만 가능합니다.** 필드·레코드 권한과 워크스페이스의 이용 기간·IP 접근 정책도 적용됩니다.

### 연결 방법

{% hint style="info" %}

{% endhint %}
