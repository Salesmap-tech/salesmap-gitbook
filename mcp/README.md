# MCP

세일즈맵을 Codex, ChatGPT, Claude에 연결하면 대화로 영업 데이터를 찾고 업무를 처리할 수 있습니다.

> 내가 담당하는 딜은 몇 건이고, 금액 합계는 얼마야?

> 클라우드 전환 프로젝트의 최근 활동과 노트를 요약해줘.

> 이 딜에 오늘 미팅 내용을 노트로 남겨줘.

딜·고객·회사를 검색하거나 할 일을 확인하고, 노트와 견적을 만들 수 있습니다. 지원하는 작업과 요청 예시는 [사용하기](use-cases.md)에서 확인하세요.

### 이용 조건

Professional 이상 플랜의 워크스페이스와 세일즈맵 계정이 필요합니다.

연결할 때 ‘조회만’ 또는 ‘조회 및 변경’을 선택합니다. ‘조회 및 변경’을 선택해도 세일즈맵에서 조회 권한만 가진 사용자는 조회만 할 수 있습니다.
