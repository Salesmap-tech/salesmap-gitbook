# MCP

세일즈맵을 ChatGPT(Codex)와 Claude에 연결하면 대화로 데이터를 찾고 업무를 처리할 수 있습니다.

> 내가 담당하는 딜은 몇 건이고, 금액 합계는 얼마야?

> 클라우드 전환 프로젝트의 최근 활동과 노트를 요약해줘.

> 이 딜에 오늘 미팅 내용을 노트로 남겨줘.

딜·고객·회사를 검색하거나 할 일을 확인하고, 노트와 견적을 만들 수 있습니다.

### 이용 조건

Professional 이상 플랜의 워크스페이스와 세일즈맵 계정이 필요합니다.

### 호출 한도

MCP 도구 호출은 워크스페이스·사용자별로 **조회 초당 4회, 쓰기 초당 2회**로 각각 제한됩니다. 같은 워크스페이스의 같은 사용자는 연결한 AI 서비스나 연결·토큰이 달라도 이 한도를 함께 사용합니다.

- 쓰기에는 레코드 일괄 수정·생성·삭제, 노트·할 일·견적·속성 생성, 피드백 제출이 포함됩니다. 나머지 조회 도구는 조회 한도를 사용합니다.
- 연결 초기화와 도구 목록 조회는 업무 도구 호출 한도에 포함되지 않습니다. 여러 도구를 한 요청에 담으면 각 도구 호출을 조회·쓰기로 나누어 집계합니다.
- 조회·쓰기가 섞인 요청에서 어느 한쪽 한도를 초과하면 요청 전체가 거절되며, 해당 요청으로 양쪽 한도를 차감하지 않습니다.

한도를 초과하면 도구 실행 전에 HTTP `429`(`rate_limit_exceeded`)가 반환됩니다. `Retry-After` 헤더에 안내된 초 단위 시간만큼 기다린 뒤 다시 요청하세요.

호출 한도를 확인하는 저장소가 일시적으로 응답하지 않으면 HTTP `503`(`temporarily_unavailable`)이 반환됩니다. 잠시 후 다시 시도하세요.
