# MCP

세일즈맵을 ChatGPT(Codex)와 Claude에 연결하면 대화로 데이터를 찾고 업무를 처리할 수 있습니다.

> 내가 담당하는 딜은 몇 건이고, 금액 합계는 얼마야?

> 클라우드 전환 프로젝트의 최근 활동과 노트를 요약해줘.

> 이 딜에 오늘 미팅 내용을 노트로 남겨줘.

딜·고객·회사를 검색하거나 할 일을 확인하고, 노트와 견적을 만들 수 있습니다.

### 이용 조건

Professional 이상 플랜의 워크스페이스와 세일즈맵 계정이 필요합니다.

### 도구 호출 한도

MCP 도구 호출은 **워크스페이스·사용자별 초당 2회**까지 가능합니다. 같은 사용자가 같은 워크스페이스에 여러 AI 앱이나 연결·토큰으로 접근해도 한도를 공유합니다. 연결 초기화와 도구 목록 조회는 이 한도를 소모하지 않습니다.

한도를 넘으면 도구를 실행하기 전에 HTTP `429`(`rate_limit_exceeded`)를 반환합니다. 응답의 `Retry-After` 헤더에 안내된 시간(초)만큼 기다린 뒤 다시 요청하세요. 호출 한도 저장소에 장애가 발생하면 HTTP `503`(`temporarily_unavailable`)을 반환하며 도구를 실행하지 않습니다.
